A tela do perfil mostra nome e foto, mas a resposta pode trazer muito mais. Quem fez o pedido recebe status, headers e corpo completos, mesmo que a interface esconda parte deles.

Uma Application Programming Interface (API), interface pela qual sistemas trocam dados, costuma responder em JavaScript Object Notation (JSON), formato textual de pares e listas. Se o JSON inclui `password_hash` ou token de redefinição, esconder o campo na tela não remove o vazamento.

Erros também falam. Uma *stack trace*, ou pilha de execução, lista as chamadas percorridas até a falha e pode revelar caminhos de arquivo, bibliotecas e consultas. Em produção, o cliente recebe mensagem genérica e um código de correlação; o detalhe fica no log protegido. Headers como `X-Powered-By` ainda podem anunciar tecnologia e versão sem necessidade.

O garçom traz o prato e também a comanda completa da cozinha. Você só precisava do prato, mas toda a comanda chegou à mesa.

</Callout>

A decisão é minimizar no servidor: selecionar campos de saída, reduzir erros e remover assinaturas desnecessárias.
