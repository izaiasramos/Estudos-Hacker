Toda resposta do servidor é lida inteira por quem fez o pedido. A tela mostra o nome e a foto, mas o navegador recebeu o JSON todo, os headers todos e, se algo quebrou, a mensagem de erro do jeito que saiu. Exposição de dados sensíveis é quando essa resposta carrega mais do que o cliente precisa.

O vazamento costuma aparecer em três lugares. Campos sobrando: a rota devolve o registro do banco inteiro, com `password_hash`, token ou e-mail de outra pessoa. Erro detalhado: a pilha do erro sai com caminho de arquivo, versão de biblioteca e a consulta que falhou. Assinatura do servidor: headers como `X-Powered-By` anunciam framework e versão.
