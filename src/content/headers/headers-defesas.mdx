Depois de reduzir o que sai, o servidor orienta o navegador com **cabeçalhos de segurança**. Cada um cuida de um comportamento. Sem eles, o navegador usa o padrão, que costuma ser o mais permissivo.

- **CSP** (*Content Security Policy*): define o que a página pode executar e carregar. Um *nonce* aleatório por resposta autoriza os scripts legítimos sem liberar qualquer script embutido.
- **HSTS** (*HTTP Strict Transport Security*): manda o navegador usar só HTTPS nos próximos acessos. HTTPS é o HTTP protegido por criptografia (TLS).
- **frame-ancestors:** limita quais sites podem colocar a sua página dentro de um quadro (*frame*).
- **X-Content-Type-Options: nosniff:** impede o navegador de "adivinhar" um tipo diferente do `Content-Type`, que é o rótulo de formato declarado pelo servidor.
- **Referrer-Policy:** limita quanto do endereço de origem acompanha a navegação.

<Code caption="Políticas em uma resposta">
```http
Content-Security-Policy: default-src 'self'; script-src 'self' 'nonce-…' 'strict-dynamic'; frame-ancestors 'self'; object-src 'none'
Strict-Transport-Security: max-age=63072000; includeSubDomains
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
```
</Code>

<Callout tone="armadilha">
`script-src 'self' 'unsafe-inline'` parece proteção, mas libera scripts embutidos, inclusive um injetado. A CSP reduz o impacto do XSS (script indevido rodando no seu site). Ela não corrige a falha que permitiu a injeção.
</Callout>

<Glossary term="Nonce" text={"Um código aleatório que muda a cada vez que a página é aberta. O site só deixa rodar os scripts que trazem esse código. Um script falso colocado por um atacante não sabe o código e é bloqueado."} example={"O site gera o código K3x9 e escreve nos seus próprios scripts. Um script injetado, sem K3x9, não roda."} />

**Em resumo:** dados mínimos reduzem o que vaza. Políticas explícitas limitam o que o navegador faz.
