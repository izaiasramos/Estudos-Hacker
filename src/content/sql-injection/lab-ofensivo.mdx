## Mão na massa: veja a falha acontecer no seu computador

**Onde se faz isso?** Num arquivo de servidor, não no console do navegador. SQL Injection acontece no código que fala com o banco, então vamos escrever um mini "servidor" de pedidos com um banco SQLite em memória. Precisa do Node.js 22.5 ou mais novo (`node -v` mostra a versão). Tudo roda **só na sua máquina**, em arquivos que você mesmo cria.

1. Crie uma pasta `praticar-sql` e, dentro dela, o arquivo `inseguro.mjs`.
2. Cole o código abaixo.
3. No terminal, rode `node inseguro.mjs`.

<Code caption="inseguro.mjs: a busca que cola o email no SQL">
```js
import { DatabaseSync } from "node:sqlite";

const db = new DatabaseSync(":memory:");
db.exec(`
  CREATE TABLE pedidos (id INTEGER, email TEXT, item TEXT);
  INSERT INTO pedidos VALUES (1, 'alice@exemplo.test', 'Margherita');
  INSERT INTO pedidos VALUES (2, 'bruno@exemplo.test', 'Calabresa');
`);

// INSEGURO: o email é colado dentro do texto SQL
function listarPedidos(email) {
  const sql = "SELECT item, email FROM pedidos WHERE email = '" + email + "'";
  console.log("SQL enviado:", sql);
  return db.prepare(sql).all().map((linha) => `${linha.email}: ${linha.item}`);
}

console.log(listarPedidos("alice@exemplo.test"));
// Um "email" que muda a frase SQL:
console.log(listarPedidos("alice@exemplo.test' OR '1'='1"));
```
</Code>

**O que observar:** a primeira chamada mostra só a Alice. Na segunda, o "email" tem um pedaço extra (`' OR '1'='1`). Olhe a linha "SQL enviado": o texto virou outra frase, cujo filtro é verdadeiro para todas as linhas. Resultado: o pedido do Bruno aparece na lista da Alice.

<Callout tone="dev">
Na vida real, esse "email" viria de um campo de formulário, e a função `listarPedidos` estaria dentro da rota do servidor. A mecânica é idêntica. Pratique **apenas** nos arquivos que você criou ou em ambientes autorizados.
</Callout>

**Seu desafio:** adicione uma coluna `senha` à tabela e mude só o texto passado à função para fazer a busca mostrar dados que ela não devia. Depois siga para a unidade de defesa e conserte.
