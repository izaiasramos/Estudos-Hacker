A defesa principal decorre diretamente do modelo mental: fixe a estrutura SQL e envie valores por parâmetros. No driver usado pelo laboratório, `?` marca o lugar e `[email]` leva o valor separadamente.

<Code caption="Mesma busca, com papéis separados">

```js
db.query("SELECT id FROM usuarios WHERE email = ?", [email])
```

</Code>

Um **ORM** — biblioteca de Mapeamento Objeto-Relacional — costuma oferecer métodos que constroem SQL a partir de objetos ou argumentos. Use a interface que trata valores como parâmetros. Inserir manualmente uma variável em uma string SQL continua inseguro, mesmo dentro de um projeto que usa ORM.

Além da correção principal, há camadas que reduzem risco e impacto:

<InlineMission id="sql-camadas" />

<Glossary term="menor privilégio" text="Princípio de conceder à conta do aplicativo somente as permissões necessárias para sua função. Se algo falhar, o alcance possível fica menor." />

Validar o formato da entrada também é útil. A validação responde “este valor faz sentido para esta função?”. A parametrização responde uma pergunta diferente: “este valor pode mudar a estrutura SQL?”. As duas podem coexistir, mas só a segunda fecha esta fronteira.

<Glossary term="WAF" text="Sigla de Web Application Firewall (Firewall de Aplicação Web): camada diante da aplicação que examina requisições e tenta bloquear padrões suspeitos antes que cheguem ao código." />

<Callout tone="armadilha">

Um WAF não transforma uma consulta concatenada em parametrizada. Ele pode bloquear parte do tráfego, mas pode não reconhecer todas as formas, não cobre necessariamente dados já armazenados e não corrige a causa no código.

</Callout>

<Callout tone="dev">

Ordem de decisão: primeiro elimine a concatenação de valores no SQL; depois confirme regras de negócio com validação; limite a conta do banco; use monitoramento e WAF como camadas adicionais. Não troque a defesa estrutural por uma barreira periférica.

</Callout>

**Síntese:** parâmetros corrigem a causa; validação melhora a entrada; menor privilégio reduz impacto; WAF adiciona observação e bloqueio parcial.
