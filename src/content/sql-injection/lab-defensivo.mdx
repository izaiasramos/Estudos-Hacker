Sua vez de consertar. Você vai editar duas funções fictícias:

- `findUser` busca uma pessoa pelo email.
- `listOrders` lista só os pedidos desse email.

**O que fazer:** nas duas funções, troque o email colado no texto por um `?` e passe o `email` numa lista separada, assim:

<Code caption="O formato que o laboratório reconhece">
```js
db.query("SELECT ... WHERE email = ?", [email])
```
</Code>

A tarefa de negócio não muda. Só muda o caminho do valor até o banco.

<Callout tone="conceito">
Este editor **não roda o seu JavaScript e não consulta um banco**. Ao enviar, o servidor faz uma leitura de texto: procura as duas funções, recusa as formas conhecidas de concatenar o `email` e confere se o padrão com `?` está lá. Verde quer dizer "a estrutura está certa", não "o login funciona".
</Callout>

A leitura é bem estreita de propósito. Mantenha os nomes `findUser` e `listOrders`, a ordem das funções e a chamada `db.query`. Num projeto real, você combinaria essa revisão de código com testes que executam de verdade. Aqui, só a revisão existe.

<Callout tone="dev">
Se a inspeção apontar uma das funções, leia a mensagem como "o padrão de texto que eu esperava não está lá", e não como resultado de uma execução.
</Callout>

**Para concluir:** as duas consultas precisam ter a instrução fixa e o `email` passado em separado.
